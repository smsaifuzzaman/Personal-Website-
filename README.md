# Personal-Website-

A Persona 3-inspired personal portfolio site with animated menu navigation, themed transitions, social profile cards, and background music.

## Live Site

https://persona3-website-main.vercel.app

## What This Includes

- Persona-style landing menu and transitions
- About section with interactive info cards
- Socials section with platform profile snapshots
- Background music with mute/unmute toggle
- Vite + React app with Vercel production deployment

## Tech Stack

- React
- React Router
- Framer Motion
- Vite
- Git LFS (for large media assets)

## Run Locally

### Prerequisites

- Node.js `20.19+` (or `22.12+`)
- npm

### Setup

```bash
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```

## Deploy (Vercel)

This project is configured to deploy on Vercel.  
If importing from GitHub, make sure Git LFS is enabled in Vercel project settings because several assets are tracked via LFS.
